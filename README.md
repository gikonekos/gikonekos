# gikonekos

## About

Original developer of the 1994 PC-98 doujin game **Space Panicco** (すぺーす ぱにっ娘) — graphics and BGM.

I preserve and reconstruct historical software from the Japanese retro computing scene, and publish open specifications and tools related to that culture.

日本のレトロコンピュータ文化に関する歴史的ソフトウェアの保存・再構築、および関連するオープンな仕様・ツールの公開を行っています。

**Website:** [motoikenkichi.com](https://motoikenkichi.com/)

- SHARP **PC-E500** series pocket computers  
- NEC **PC-9801** DOS platform

## Projects by category

### Retro archives (PC-E500 / PC-98)

| Repository | What it is |
|------------|------------|
| [PLAY3-Archive](https://github.com/gikonekos/PLAY3-Archive) | Three-voice buzzer music driver (Pocket Computer Journal, 1993). Real-hardware verified. *Bottakuri Shouten* from this set is used as BGM in Space Panicco. |
| [Building-Rescue-Archive](https://github.com/gikonekos/Building-Rescue-Archive) | PC-E500 action game (1994). Pseudo grayscale LCD technique on title/ending. |
| [Space-Panicco-Archive](https://github.com/gikonekos/Space-Panicco-Archive) | PC-98 platform action game (1994). Original author archive; includes VMAP editor. |
| [pc-e500-software-guide](https://github.com/gikonekos/pc-e500-software-guide) | English introduction / guide to SHARP PC-E500 software. |
| [sc62015-opcode-reference](https://github.com/gikonekos/sc62015-opcode-reference) | Reconstructed SC62015 opcode reference from historical printed material. |

### Open specification (shared culture)

| Repository | What it is |
|------------|------------|
| [aaaps](https://github.com/gikonekos/aaaps) | **AAAPS** (Ascii Art Appropriation Protection Specification) — license / governance template to keep shared AA and internet characters from exclusive enclosure. |
